# AWS Architecture Icons

Place a curated subset of AWS Architecture Icons here (SVG or PNG) for air-gapped use.

- Download from: https://aws.amazon.com/architecture/icons/
- Use in accordance with AWS usage guidelines.
- Suggested subset: compute (Lambda, EC2), storage (S3), database (RDS), networking (API Gateway).
- Name files by service type (e.g. `Amazon-S3.svg`, `AWS-Lambda.svg`) for mapping from `ExternalSystem.vendor`/`type`.
